ForgottenL Client - one step left
==================================

This client is fully configured to connect to ForgottenL
(forgottenl.me:7171, Tibia client version 8.70) and is ready
to run - except for one thing we deliberately did NOT include:

    Tibia.dat
    Tibia.spr   (or Tibia.cwm)

These two files contain CipSoft's own game sprites and object data for
client version 8.70. They are copyrighted, we don't have a verified clean
copy to hand out, and we are not going to bundle files we can't vouch for.

What to do:
  1. Get a legitimate copy of these two files for Tibia client 8.70.
     The classic way: install an old Tibia 8.70 client you already have
     a right to use, and copy Tibia.dat / Tibia.spr out of it.
  2. Drop both files into this folder:

         <where you installed ForgottenL>\data\things\870\

  3. Launch ForgottenL (the desktop/start menu shortcut). It will find the
     files automatically - no further configuration needed.

If you don't have a copy and aren't sure where to get one, ask on the
ForgottenL support channels (see the Support List on the website). We are
not going to point you at a random download link from a forum - neither
should you trust one without checking it yourself first.
